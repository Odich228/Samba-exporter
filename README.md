# 📊 Samba Prometheus Exporter

Мощный и эффективный экспортер для Prometheus, предназначенный для глубокого мониторинга состояния файлового сервера Samba (SMB). В отличие от стандартных решений, данный экспортер предоставляет детальную аналитику по активным сессиям, блокировкам файлов и физическому состоянию дисковых ресурсов в реальном времени.

---

## 🌟 Основные возможности

*   **Мониторинг сессий (Audit)**:
    *   Имена активных пользователей (с фильтрацией системных аккаунтов).
    *   IP-адреса клиентов для аудита безопасности.
    *   Версии используемых протоколов (от SMB2.02 до SMB3.11).
*   **Контроль файлового доступа**:
    *   Общее количество открытых файлов и активных блокировок.
    *   Полные пути к файлам, которые в данный момент заблокированы пользователями.
*   **Интеллектуальный мониторинг дисков**:
    *   **Auto-discovery**: Автоматическое обнаружение шар напрямую из `smb.conf`.
    *   **Parallel Processing**: Параллельный расчет занимаемого места (`du`) без блокировки сбора основных метрик.
    *   **FS Stats**: Сбор данных о свободном месте на разделах через системные вызовы ОС (аналог `df`).
*   **Диагностика системы**:
    *   Встроенные метрики производительности Go (память, горутины).
    *   Метрика `scrape_duration` для оценки нагрузки, создаваемой экспортером.

---

## 🛠 Системные требования

*   **ОС**: Linux (Arch, Debian, Ubuntu, CentOS, РЕД ОС и др.).
*   **Samba**: версия 4.10+ (обязательна поддержка флага `--json` в утилите `smbstatus`).
*   **Go**: 1.21+ (для самостоятельной сборки).
*   **Права**: Экспортер должен запускаться с правами, достаточными для выполнения `smbstatus` (обычно `root`).
